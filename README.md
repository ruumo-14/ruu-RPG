# Ruu RPG — Dodge & Survive

ブラウザで遊ぶ、ドット絵風の弾幕回避ゲームです。プレイヤーは攻撃せず、敵の弾を避けて生き残り、GOLDを集めて次のステージを解放します。

## ファイル構成

- `index.html` — ゲームの入口
- `rpg.html` — ゲーム画面（単体起動用）
- `rpg.css` — 全画面表示とタッチ操作のスタイル
- `rpg.js` — 移動、弾幕、当たり判定、GOLD、ステージ進行
- `README.md` — 説明書

## 起動方法

4つのゲームファイルを同じフォルダに置き、`index.html` をブラウザで開きます。GitHub Pagesでも公開できます。

## 操作方法

- 移動：矢印キーまたは WASD
- タイトル画面：Space / Enter
- ステージ選択：1 または 2
- ゲームオーバー後：Enterで再挑戦
- ステージ選択に戻る：Esc
- タッチ端末：画面下の方向ボタンと START

## ステージ

### Stage 1
プレイヤーを狙う直線弾と、敵の位置から全方向へ広がる弾を組み合わせます。

### Stage 2
敵から放射状に広がる弾幕に加え、ときどき画面端付近に予告が出て、そこから扇状の弾が発射されます。

各ステージは25秒間生き残るとクリアになります。生存中は時間に応じてGOLDを獲得し、クリア報酬も得られます。Stage 2の解放には50 GOLDが必要です。
