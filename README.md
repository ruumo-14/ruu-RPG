
# Ruu RPG — Dodge & Survive

ドット絵風の弾幕回避ゲームです。

敵を攻撃することはできません。弾を避けて生き残り、GOLDを集めながらステージを解放していきます。

## ファイル構成

- `index.html` — タイトル画面・ゲームの入口
- `rpg.html` — ゲーム画面
- `rpg.css` — 全画面表示とデザイン
- `rpg.js` — 移動・弾幕・GOLD・ステージの処理
- `README.md` — 説明書

## 操作方法

- 移動：矢印キーまたは WASD
- タイトル画面：Space または Enter
- Stage 1：ステージ選択画面で 1
- Stage 2：ステージ選択画面で 2
- 再挑戦：ゲームオーバー後に Enter
- タイトルへ戻る：ステージ選択画面で Esc
- タッチ端末：画面下の方向ボタン

## GOLDと難易度

- 10秒ごとにGOLDを獲得します。
- 30秒経過するごとにGOLDの獲得量が2倍になります。
- 敵の弾も30秒ごとに速くなり、後半ほど加速幅が大きくなります。
- 時間制のステージクリアはありません。
- HPがなくなるまで戦闘が続きます。

## ステージ

### Stage 1
プレイヤーを狙う直線弾と、敵から全方向に広がる弾を組み合わせます。

### Stage 2
敵から放射状に広がる弾幕に加え、画面端付近に予告が出てから扇状の弾が発射されます。

Stage 2の解放には50 GOLDが必要です。

## 起動方法

すべてのゲームファイルを同じフォルダに配置し、`index.html` をブラウザで開きます。

GitHub Pagesでも公開できます。
