# ruu-RPG

このリポジトリはブラウザ上で動くシンプルな RPG（HTML/CSS/JavaScript）です。

## 概要
- 言語: HTML, CSS, JavaScript
- 動作: 静的なウェブページとして動作します。index.html をブラウザで開くか、簡易サーバで配信して実行してください。

## ローカルでの起動方法
方法1: ファイルを直接開く
1. リポジトリをクローンまたはダウンロード
2. `index.html` をブラウザで開く

方法2: 簡易HTTPサーバを使う（推奨）
- Python 3 があれば:
  - ターミナルでリポジトリのルートへ移動
  - `python -m http.server 8000` を実行
  - ブラウザで `http://localhost:8000` を開く

- npm パッケージ `serve` を使う方法:
  - `npm install -g serve`
  - `serve .`
