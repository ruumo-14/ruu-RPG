
# 🎮 Ruu RPG

ブラウザで遊べる、シンプルなターン制RPGゲームです。

敵と戦って経験値やゴールドを獲得し、レベルアップしながら次々と現れる敵に挑戦しよう！

## ✨ ゲームの特徴

- 🎮 タイトル画面からゲームを開始
- ⚔️ プレイヤーと敵との戦闘
- ❤️ HPと回復アイテム
- 🛡️ 防御によるダメージ軽減
- 📈 経験値とレベルアップ
- 💰 ゴールドの獲得
- 🛒 回復アイテムを購入できるショップ
- 👾 複数の敵と連続して戦闘
- 🔄 ゲームオーバー後のリスタート
- 📱 スマートフォンにも対応したレイアウト

## 📁 ファイル構成

```text
ruu-RPG/
├── index.html   # タイトル画面・ゲームの入口
├── rpg.html     # ゲーム画面のHTML
├── rpg.css      # ゲームのデザイン
├── rpg.js       # 戦闘やレベルアップなどの処理
└── README.md    # ゲームの説明書
```

## 🚀 起動方法

### 方法1：ブラウザで起動

1. このリポジトリのファイルをダウンロードする。
2. `index.html`、`rpg.html`、`rpg.css`、`rpg.js` を同じフォルダに配置する。
3. ブラウザで `index.html` を開く。
4. タイトル画面で Space キーを押してゲームを開始する。

### 方法2：GitHub Pagesで公開

1. GitHubでこのリポジトリを開く。
2. **Settings → Pages** を開く。
3. 公開元のブランチとフォルダを設定する。
4. 保存して、公開URLからゲームを開く。

※ 公開設定や反映には少し時間がかかる場合があります。

## 🕹️ 操作方法

| 操作 | 内容 |
|---|---|
| Space | タイトル画面からゲーム開始 |
| 攻撃ボタン | 敵にダメージを与える |
| 回復ボタン | 回復アイテムを使う |
| 防御ボタン | 次の敵の攻撃を軽減する |
| 購入ボタン | 回復アイテムを購入する |
| もう一度挑戦 | ゲームオーバー後に再開する |

## ⚔️ 戦闘システム

敵を倒すと経験値とゴールドを獲得できます。

経験値が一定値に達するとレベルアップし、最大HPと攻撃力が上昇します。

敵の攻撃は時間経過で行われます。敵を倒したときは、次の戦闘に移る前に攻撃タイマーをリセットします。

## 💰 ゴールドとショップ

敵を倒すとゴールドを獲得できます。

ショップではゴールドを使って回復アイテムを購入できます。

現在のバージョンでは、戦闘ごとの獲得ゴールドと所持ゴールドを分けて管理しています。
